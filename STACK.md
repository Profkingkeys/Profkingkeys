# Stack Taxonomy

## Demonstrated in public repositories

- JavaScript and Node.js
- HTML, CSS, browser APIs, responsive UI
- Three.js and WebGL simulation foundations
- REST and OpenAPI contracts
- MySQL schemas and tenant-oriented design
- Android, Kotlin, Java, and WebView bridges
- GitHub Actions, GitHub Pages, automated tests
- OTLP/OpenTelemetry-compatible tracing concepts
- AI agents, tool registries, provider evaluation, structured outputs
- AI security boundaries, API-key handling, and human review patterns
- Solana-oriented metadata, IPFS, and wallet concepts

## Demonstrated in connected/private product work

- Express, JWT, Passport, bcrypt, Socket.IO, Nodemailer
- FastAPI, Groq, OpenAI-compatible APIs, NVIDIA inference, Edge TTS
- MongoDB, Mongoose, Supabase, Netlify Functions

## Active exploration

- Google Filament native rendering
- privacy-preserving learning analytics
- adaptive AI simulation feedback
- evidence graphs and biomedical research tooling

Exploration is kept separate from demonstrated implementation so the profile remains technically credible.
