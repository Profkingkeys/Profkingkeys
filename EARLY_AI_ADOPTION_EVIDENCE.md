## How to present original evidence

1. Run the exact Gmail query in the relevant signed-in account and open the original message.
2. For private review, capture the **subject, sender, recipient, and full sent timestamp** in a screenshot, or inspect **More → Show original** to see the original headers.
3. If sharing publicly, redact the personal recipient address, routing IDs, message-ID, verification tokens, and tracking links as appropriate. Never publish an active login or verification link.
4. State what each document proves. An informational email is not proof of an API subscription or use; a waitlist receipt is not proof of access; the May 2023 Bing welcome message **does** confirm that an access invitation was sent.

These search queries are **reproducibility instructions**, not public links to private email messages. A recruiter cannot retrieve the message without permission from the mailbox owner.
