# Profile settings and publishing

Your personal **Settings → Public profile** page contains the bio, website and social fields. It does not contain repository Pages settings.

Suggested bio (within GitHub's 160-character limit):

> AI product engineer & PharmWeb3 founder. Pharmacy student building healthcare tools, 3D learning games and practical AI guides.

Use a plain URL in the website field: `https://pharmweb3.com/portfolio`. Do not paste Markdown brackets into URL fields. Social fields: `https://x.com/Profkingkeys` and `https://www.linkedin.com/in/prof-king-keys-110a24229`.

On the public profile, choose **Customize your pins** and select PharmWeb3, Pharma-Simulation, Kid-Simulation, Ai-ebooks and Simulation-Games. A sixth pin can be your strongest independently demonstrated project; another empty repository is unnecessary.

## Pages belongs to each repository

Open the repository, then **Settings → Pages → Build and deployment → Source: GitHub Actions**. On a narrow screen, Settings may be in the repository navigation overflow menu.

- [Pharma Simulation](https://github.com/Profkingkeys/Pharma-Simulation/settings/pages)
- [KidSim](https://github.com/Profkingkeys/Kid-Simulation/settings/pages)
- [AI Library](https://github.com/Profkingkeys/Ai-ebooks/settings/pages)
- [Simulation collection](https://github.com/Profkingkeys/Simulation-Games/settings/pages)
- [PharmWeb3](https://github.com/Profkingkeys/PharmWeb3/settings/pages)

Then run the corresponding deployment workflow from Actions. The deployment job reports the actual URL. Offline releases work without enabling Pages.

The old arrow pad was GitHub's embedded Mermaid diagram viewer. The profile now uses a static banner and readable steps, so there is no pan/zoom controller to position or reverse.
